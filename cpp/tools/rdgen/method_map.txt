# EBNF nonterminal → C++ symbol. Owned by adl2_rdgen (see RDGEN.md).
#
# Columns: name  symbol  role  [notes…]
#   name   hyphenated EBNF production, lexer token, or * for extras
#   symbol parse_* / helper / TokKind note
#   role   generate | generate-later | hook | helper | extra | token
#
# generate        = emitter must classify + write the method body
# generate-later  = mechanical enough, not in this slice; method must exist
# hook            = hand-written; EBNF is incomplete or contextual
# helper          = not a parse_* production (peek / predicate)
# extra           = parse_* (or free function) with no EBNF production
# token           = lexer class referenced from the EBNF, not a parse method
